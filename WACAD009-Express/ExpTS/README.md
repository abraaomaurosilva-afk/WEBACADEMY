# ExpTS - Express com TypeScript

Versão em TypeScript do Exercício 1 com Express.

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm start
```

## Compilar

```bash
npm run build
```

## Produção

```bash
npm run start:prod
```

A aplicação usa a porta definida em `.env` ou, na ausência dela, a porta `3333`.
