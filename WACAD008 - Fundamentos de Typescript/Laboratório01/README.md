# Laboratório01

Aplicação simples de lembretes com:

- autenticação por usuário e senha;
- criação de lembretes;
- edição de lembretes;
- exclusão de lembretes;
- data e hora de inserção automática;
- data limite;
- persistência dos dados no localStorage.
